# Мини-ассистент по обработке содержания документов

CLI-ассистент, который решает задачи по нормативно-техническим документам из локального архива: навигация по содержанию с вложенными уровнями, загрузка страниц, ответы с цитатами на источники.

## Возможности

- **Список документов** — перечень документов архива с фильтром по ключевым словам названия и коду.
- **Навигация по содержанию** — дерево заголовков с номерами пунктов (1.1.2), диапазонами страниц и вложенными уровнями; раскрытие по номеру пункта и глубине.
- **Загрузка страниц** — по номерам страниц или по номерам пунктов (clause).
- **Ответы с цитатами** — каждое утверждение снабжается ссылкой `[doc_id:N, стр.M]`.

## Структура архива

Каталог `data/` содержит zip-архивы документов:

```
text
document.zip
├── toc.json                 # оглавление: дерево заголовков (clause, level, page_start, page_end)
├── metadata.json            # код, название документа
└── pages/
    ├── 001.md               # текст страницы 1
    └── ...
```

Пример `toc.json`:

```json
{
  "pages_count": 150,
  "tree": [
    {
      "title": "Введение",
      "clause": "1",
      "level": 1,
      "page_start": 1,
      "page_end": 5,
      "children": [
        { "title": "Цели", "clause": "1.1", "level": 2, "page_start": 2, "page_end": 2, "children": [] }
      ]
    }
  ]
}
```

## Установка

```
pip install openai python-dotenv
```

## Настройка LLM

Параметры берутся из переменных окружения / `.env` (см. `.env.example`) или передаются аргументами CLI (приоритет выше):

- `OPENAI_API_KEY` — ключ API
- `OPENAI_BASE_URL` — адрес OpenAI-совместимого сервера (для локальных серверов можно без ключа)
- `OPENAI_MODEL` — модель (по умолчанию `gpt-4o-mini`)

## Запуск

```
python cli.py
python cli.py --api-key sk-... --base-url http://localhost:8000/v1 --model gpt-4o-mini
```

## Инструменты ассистента

| Инструмент | Назначение |
|---|---|
| `list_documents` | Список документов; фильтры `query` (слова названия) и `doc_code` (подстрока кода) |
| `toc_navigate` | Содержание: `clause` — номер пункта для раскрытия, `depth` — уровни вложенности (по умолчанию 1, выводится полностью; при depth > 1 лимит 300 строк) |
| `get_pages_by_clause` | Страницы пунктов по номерам (например `1.1.2`); максимум 3 страницы на пункт |
| `get_page_markdown` | Страницы по номерам страниц; максимум 30 за вызов |

## Файлы

- `cli.py` — точка входа (CLI-чат)
- `assistant.py` — оркестрация: цикл вызовов инструментов, wind-down, review, история диалога
- `prompts.py` — системный промпт и определения инструментов
- `archive.py` — работа с zip-архивами: парсинг и дедупликация toc, навигация, страницы
- `config.py` — настройки
- `example/` — образец реализации (промпт и пайплайн ПКБ-ассистента)

## Ограничения

- Содержание документов в системный промпт не передаётся — структура доступна только через `toc_navigate` (оглавления слишком объёмные).
- Ответ формируется исключительно на основе загруженных страниц; при отсутствии данных ассистент сообщает об этом.
